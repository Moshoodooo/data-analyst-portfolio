## 🚀 Project Architecture & Pages
1. **Home (`index.html`)**: Professional introduction, hero section, key metrics, and featured project previews.
2. **About (`about.html`)**: Academic biography, computer science background, and educational distinction.
3. **Skills (`skills.html`)**: Interactive proficiency indicators across SQL, Python, Power BI, Tableau, Excel, and data cleaning.
4. **Projects Gallery (`projects.html`)**: Dynamic project grid with real-time keyword search and category filtering.
5. **Project Deep-Dive (`project-details.html`)**: Individual case study breakdowns with business problems, datasets, cleaning steps, code snippets, and recommendations.
6. **Experience (`experience.html`)**: Career timeline and continuous professional education.
7. **Certifications (`certifications.html`)**: Verified professional credentials.
8. **Resume (`resume.html`)**: Executive web CV presentation with PDF download support.
9. **Contact (`contact.html`)**: Functional contact form with validation and direct communication channels.

## 🛠️ Running the Portfolio Locally
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension by Ritwick Dey in VS Code.
3. Right-click on `index.html` and select **"Open with Live Server"**.
4. The website will open in your default browser at `http://127.0.0.1:5500`.
